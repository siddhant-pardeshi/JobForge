Orientation

What JobForge does for you

JobForge is a job hunt cockpit that runs on your own machine. It watches real employer career boards, scores every opening against your actual resume, screens recruitment fraud, drafts your documents, and keeps the pipeline organized. You stay in control of every submission.

Real openings only

5,700 plus live postings from 21 boards verified against their official endpoints: Zscaler Pune, Databricks, Meesho, Rubrik, Okta, Stripe, GitLab, Figma, MongoDB, OpenAI and more.

Scores that explain themselves

Seven weighted components per job, every matched and missing skill visible, every exclusion kept in its lane where you can audit it.

Fraud screened

Fee demands, UPI traps, fake sender domains, lying link text. One click inside Gmail and Outlook tells you if a mail is safe to answer.

Documents grounded in truth

Cover letters built from your resume against each job description, plus a 100 character referral note ready to send to anyone at the company.

A board that organizes itself

Forge a packet, the card moves. Schedule a round, it moves and reminds you an hour before. Attach a receipt, the submission counts.

Free, private, yours

Runs locally. Resume and keys never leave your machine. Works fully without any AI key. MIT licensed, forever.

Part 2 · Setup

Run it on Windows

1
Install Node.js 20 or newer

Download the LTS installer from nodejs.org and run it. Verify in a terminal:

node --version # expect v20.x or v22.x
2
Get the project

Clone it, or download the ZIP from GitHub and extract it.

git clone https://github.com/siddhant-pardeshi/JobForge.git cd JobForge
3
Install dependencies

One command, about thirty seconds. Nothing else to configure.

npm install
4
Start it

Two processes start together: the engine on port 8787 and the interface on 5173.

npm run dev
5
Open the cockpit

Go to http://localhost:5173. On first launch the onboarding wizard walks you through uploading a resume, your target locations, and the optional AI key. The 21 boards in the registry seed themselves and the first refresh starts within seconds.

Prefer one process?
npm run build npm start

Then use http://localhost:8787 only. Same app, single terminal, ideal for daily use.

Verify the install
  • npm test prints 30 passing tests
  • Sidebar shows 21 live sources
  • Jobs page fills within a minute of first launch
First load is the slow one. Scoring 5,700 jobs takes up to a minute after a fresh start. Every load after that is instant. If the board looks empty, give it one minute, it is working.

Part 3 · Foundation

Load your resume the right way

Everything in JobForge reads from one verified profile. Ten careful minutes here upgrades every score, packet and referral note the engine will ever produce for you.

1
Upload

Resume page, drop your PDF or DOCX. Parsing happens on your machine. Scanned PDFs are detected and reported, never guessed at. A paste box is there if your file is awkward.

2
Review the confidence chips

Each extracted fact carries a confidence level. Fix anything marked medium or low while the original file is still fresh in your head.

3
Correct the skill list

Remove anything stale with one click on its chip. Add missing skills by typing and pressing Enter. Skills drive 30 points of every match score, so this list is the highest leverage edit in the app.

4
Set your role families

Pick the families your resume actually supports: backend, fullstack, frontend, QA, data, cloud and so on. This drives the responsibility component, 20 more points.

5
Save and watch the board move

Saving re ranks every job instantly. Add a skill the boards ask for and watch roles jump lanes.

Do this now. Put your LinkedIn and GitHub links into the profile. The referral messages and autofill both use them.
Minimum pay field. Leave it empty if undecided. An empty floor keeps suitable roles visible instead of burying them over pay the posting never listed.

Part 6 · Documents

Forge packets: letters and referrals

Open a role, press Forge application packet. Ten seconds later you hold three weapons and a checklist. The card also lands itself on your tracker at Preparing.

Tailored cover letter

Written from your resume against this specific description. Connects your real projects to the requirements the employer listed. Copy button on top.

Referral message

About 100 characters, mentions one concrete project and the role title. Character count shown live. Copy and send to anyone at the company.

Questions list

Everything the resume cannot answer: expected pay, screening specifics. Answer these before submitting, never after.

Rules the engine enforces on itself
  • Nothing is invented. No fake employers, metrics, dates or skills. Ever.
  • Gaps stay gaps. If the description wants Redis and you never touched it, the packet says so and hands you a talking point instead of a lie.
  • With or without AI. No key gives you solid rules drafted documents. A key gives sharper wording. Same truth rules either way.
Referral math. Referred applications convert several times better than cold applies. Send the referral message to one real person per company before you submit anything cold. Search the company name plus the role on LinkedIn to find them.

Part 7 · Supply

Sources and live refresh

Every posting arrives from an official board endpoint. The registry ships with 21 verified employers and grows whenever you paste a careers URL.

1
Add any company in 20 seconds

Add a source, paste the careers page URL, for example job-boards.greenhouse.io/zscaler or jobs.lever.co/meesho. Provider and board handle are detected, the board is probed live before saving. Greenhouse, Lever and Ashby pages all work.

2
Let the scheduler work

Every board is polled on the interval you set, 20 minutes by default. Toggle it, change the number, or hit Refresh all now. New postings appear on their own.

3
Trust the closed lane

A role is marked closed only after two consecutive refreshes miss it, so a board glitch never fakes a closure. Reposts reopen automatically. The Open and Closed counters per source keep everyone honest.

Why no LinkedIn or Naukri here

Their terms prohibit automated access and the penalty lands on your account. JobForge never scrapes them. The helper extension covers both through capture while you browse.

Health at a glance

The refresh log lists every run with what changed. A failing source shows its error. Zero jobs and cannot check are always shown as different facts.

Grow your coverage. Ten minutes of pasting careers URLs from companies you admire typically adds five to ten boards. Every added board compounds into the daily refresh.

Part 8 · Defense

Scam screening and mail fraud

Recruitment fraud in India starts with a fee demand and ends with a drained account. JobForge gives you three screens, use all of them.

Paste screen

Scam page, message mode. Paste any WhatsApp forward or job ad. 18 indicators, risk band, specific advice.

Email screen

Switch to Full email mode, paste sender, reply to, subject and body. Adds domain and link lie detection.

Inbox screen

Helper extension inside Gmail and Outlook. One click on the open mail, verdict panel appears in place.

Red flags the engine hunts
SignalWhat it means
Fee or deposit demandNo real employer charges you to interview or join. Walk away.
UPI or OTP requestAccount takeover. Never share either with anyone.
Reply to mismatchReplies divert to another mailbox. Classic takeover trick.
Sender domain mismatchGmail claiming to be a company. Verify on the official site.
Link text liesText says the company, href goes elsewhere. Never click, type it yourself.
Offer without interviewSelection without evaluation does not exist.
Urgency plus moneyPressure is the product. Disengage and report.
Calibrated, not paranoid. A WhatsApp contact alone never gets branded fraud. A payment demand always blocks automation, whatever the skill match. Every verdict shows its evidence.

Part 9 · Decisions and pipeline

Relocation math and the tracker

Relocation page

Enter fixed pay or take home, deposit, moving costs. Three scenarios come back: cautious, base, favorable, each with monthly surplus, savings margin and the gap over staying in Pune.

  • Deposits are liquidity, never counted as monthly cost
  • Joining bonus and variable pay excluded from monthly figures
  • Undisclosed pay returns unknown plus the questions to ask, never a guess
  • Budgets are editable per city, your numbers beat any default
Policy checks. Set your minimum surplus and maximum upfront need in policy, and every evaluation answers yes or no against them.
Tracker page

Seven columns from Shortlisted to Offer. Cards move themselves on facts: packet forged, round scheduled, receipt attached. Manual moves always available.

  • Schedule every round with date, time and mode. Countdown chips appear on the board and Today.
  • Reminders fire one hour before each round as browser notifications.
  • A submission counts only when you attach the confirmation reference. Duplicate applies are blocked.
  • The board refreshes live every five seconds. Leave it open on a second screen.
The tracker discipline. One rule: a job never leaves your brain until it leaves the board. Every apply gets a receipt, every interview gets a round, every outcome gets recorded. The funnel data this produces is how you learn what actually works for you.

Part 11 · Browser power

The Chrome helper

Install, two minutes, once
1
Copy the token

JobForge, Settings, Helper extension card, Copy token.

2
Load it into Chrome

Type chrome://extensions, enable Developer mode, press Load unpacked, select the extension folder from the project. Pin the icon.

3
Pair it

Click the icon, paste the token, press Pair, then Test. Connected means live. Works on Edge through edge://extensions the same way.

Send to JobForge

On any posting on LinkedIn, Naukri, Greenhouse, Lever, Ashby, SmartRecruiters or Workday. One click captures it, scored and screened within a second.

Autofill with JobForge

On application forms. Fills name, contact, links, notice period, approved answers. Every value is remembered and editable, a wrong fill never repeats.

Check this email

In Gmail and Outlook. Screens the open mail, shows the verdict inline. Reads only that one mail, only when you click.

The one line that matters. The helper never presses submit. Not on any site. It stops one click short and leaves that click to you, because account bans land on you, not on tools.

Part 12 · The system

The daily power routine

Ten to fifteen quality applications in under an hour. The boards refreshed overnight, your part is judgment and clicks.

BlockTimeActions
Morning scan10 minOpen Today. Clear the deadline radar first. Shortlist or skip every hunt deck card. Decide the needs decision lane. Total: zero undecided cards.
Capture run15 minLinkedIn and Naukri with your premium filters. One click on Send to JobForge for anything decent. Ten captures in fifteen minutes is normal.
Packet batch15 minOpen each shortlisted role, forge the packet, read it, copy the referral message, send it to one real person at that company.
Apply batch15 minOpen official posting, Autofill with JobForge, review every field, attach resume, press submit yourself. Paste the confirmation into the tracker receipt.
Close out5 minRound radar check, schedule anything the recruiters sent, update outcomes. Board ends the day clean.
Weekly, 20 minutes. Add five new boards. Tune the weights in Settings based on which lanes are producing interviews. Prune skills nobody asks for, add the ones appearing in your gaps.
The rule of one. One referral message per company before any cold apply. One pass over every autofilled field before every submit. One receipt per application. Small discipline, compounding returns.

Part 13 · Edge

Pro moves and efficiency

Retune the weights

Settings, Matching weights. Interviews coming only from remote roles? Raise location weight. Missing skill gates too often? Lower skill fit a few points. The board re ranks live as you drag.

Use the score slider

Minimum score 60 on busy days, 45 when the market is quiet. The counter on every tab tells you the cost of each setting before you click.

Fix autofill once

Settings, Autofill data. Anything corrected there wins over everything else forever. Keep expected pay empty until you truly decide the number.

Work the Boolean strings

Jobs page bottom. Copy the LinkedIn string into your premium search, save it as an alert, let your subscription do night duty for free.

Trust the closed lane

A closed role that reopens jumps back to open by itself. Reapply discipline: check the tracker before any submit, duplicates are blocked anyway.

Read the funnel

Ten shortlisted and one submitted is a you problem. Fifty submitted and zero interviews is a targeting problem: raise the slider, tighten role families.

Efficiency checklist
  • Never browse postings without the helper active. Every interesting page is one click from your tracker.
  • Batch by company. Referral first, apply second, always in that order.
  • Same time daily. The routine compounds when recruiters learn your reply rhythm.
  • Friday audit. Weights, boards, skills, twenty minutes, weekly.

Part 14 · Beyond localhost

Hosting and troubleshooting

Share it or keep it, your call
1
Build and start in one process

npm run build then npm start. Everything serves from port 8787.

2
Expose it

Any HTTPS tunnel works. With cloudflared: cloudflared tunnel --url http://localhost:8787. Share the URL it prints.

3
Choose the mode

Settings, Access. Open access by default: everyone with the link uses it free. Flip to private and visitors need the six digit code. Only you can flip it, on the host machine or with the admin code printed at startup.

Fixes in thirty seconds
SymptomFix
Board empty after startFirst scoring takes up to a minute. Wait, then reload. Later loads are instant.
Port 8787 already in useAn old node process survived. Kill it by PID from netstat, or restart the machine, then npm start.
Helper test failsJobForge must be running first. Recheck token in Settings, press Test again.
Autofill filled wrong dataFix it in Settings, Autofill data, or in the helper options. Saved corrections win forever.
A board stopped returningSources page, probe icon. Boards go quiet when hiring pauses, that is the company, not the app.
AI test says unauthorizedKey pasted with a space, or no credit on a paid provider. Groq and OpenRouter keys are free to verify.
Reminders not firingBrowser notifications blocked. Allow them for localhost, keep a tab open.
Data belongs to you. Settings, Export downloads everything as JSON. Reset wipes it all locally. Nothing syncs anywhere without your tunnel running.
