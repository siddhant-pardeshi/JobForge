JobForge Helper

Pairing

Your autofill data

Sync once from JobForge, then edit anything here and press Save. These saved values are what the helper fills, so a wrong value can be corrected here and it never autofills wrong again. Last used values are also remembered automatically after every fill.

Where do these values come from?

Sync pulls your JobForge profile plus everything you approved in the app. The editor here overrides the server until you sync again, so fixes made on the road stick. The app has the same editor under Settings, Autofill data, when you want to fix values at the source.
